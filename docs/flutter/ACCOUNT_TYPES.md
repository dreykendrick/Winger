# Account Types Specification

Winger maintains a distinct **Account Type** concept separate from Roles or Organizations.

## Account Types

1. **`CUSTOMER`**: Default account type for browsing, adding items to cart, completing checkout, and tracking orders.
2. **`VENDOR`**: Merchant store owner capable of managing products, inventory SKUs, order fulfillment, and vendor payouts.
3. **`AFFILIATE`**: Promoter account capable of generating 30-day referral links, joining vendor growth campaigns, and tracking earned commissions.

A single human user profile can simultaneously maintain multiple account types.
