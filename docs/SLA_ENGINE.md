# Winger Backend V2 – SLA Engine Specification

Tracks operational response deadlines for merchants, customers, and support staff.

---

## 1. Tracked SLA Deadlines
- `VENDOR_RESPONSE`: Merchant dispatch response window (24h).
- `CUSTOMER_CONFIRM`: Buyer delivery confirmation window (48h).
- `DISPUTE_RESOLUTION`: Support team dispute resolution deadline (72h).
